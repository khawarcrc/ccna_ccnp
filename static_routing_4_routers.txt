==================================================
LAB NAME
==================================================

Lab 021 - Cisco CCNA Static Routing (Four Router Topology)

==================================================
LAB OBJECTIVE
==================================================

Configure a four-router enterprise network using static routing. Each
router is connected to two neighboring routers through Serial (WAN)
interfaces and to a local LAN through a GigabitEthernet interface.
Assign IP addresses to all router interfaces, configure PC addressing,
and manually create static routes so every LAN can communicate with
every other LAN.

==================================================
LAB TOPOLOGY
==================================================

                    192.168.12.0/24
             S0/0/0---------------S0/0/0
                R1                 R2
                |                   |
                |                   |
 192.168.13.0   |                   |   192.168.24.0
                |                   |
                |                   |
                R3-----------------R4
             S0/0/1             S0/0/1
                  192.168.34.0/24

      |                 |                 |                 |
     G0/0              G0/0              G0/0              G0/0
      |                 |                 |                 |
     SW1               SW2               SW3               SW4
    /   \             /   \             /   \             /   \
  PC1  PC2         PC3  PC4         PC5  PC6         PC7  PC8

==================================================
LAB THEORY
==================================================

Routers automatically learn only the networks directly connected to
their interfaces. They have no knowledge of remote networks until a
routing protocol or static routes are configured. In this lab we use
static routing, where every remote network is manually configured with
a destination network, subnet mask, and next-hop router. Once every
router knows how to reach all remote networks, end-to-end connectivity
is achieved across the entire topology.

==================================================
CONFIGURATION COMMANDS
==================================================

--------------------------------------------------
R1 CONFIGURATION
--------------------------------------------------

enable
configure terminal

hostname R1

interface s0/0/0
 ip address 192.168.12.1 255.255.255.0
 no shutdown
exit

interface s0/0/1
 ip address 192.168.13.1 255.255.255.0
 no shutdown
exit

interface g0/0
 ip address 10.10.10.1 255.255.255.0
 no shutdown
exit

ip route 192.168.24.0 255.255.255.0 192.168.12.2
ip route 192.168.34.0 255.255.255.0 192.168.13.3
ip route 10.20.20.0 255.255.255.0 192.168.12.2
ip route 10.30.30.0 255.255.255.0 192.168.13.3

==================================================
EXPECTED RESULT
==================================================

Each router should display three directly connected (C) networks and
five static (S) routes in the routing table. After configuring the IP
addresses on all PCs, every PC should successfully communicate with
every other PC across all four LANs through the manually configured
static routes.
