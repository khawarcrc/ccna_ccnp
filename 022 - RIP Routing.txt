==================================================
LAB NAME
==================================================
Lab 022 - Cisco CCNA RIP Routing (Four Router Topology)

==================================================
LAB OBJECTIVE
==================================================
Configure a four-router enterprise network using the RIP routing protocol (RIPv2). 
Each router is connected to two neighboring routers through GigabitEthernet (LAN/WAN) 
interfaces and to a local LAN through a GigabitEthernet interface. Assign IP addresses 
to all router interfaces, configure PC addressing, and enable RIPv2 so that every LAN 
can communicate with every other LAN dynamically.

==================================================
LAB THEORY
==================================================
Routers automatically learn only the networks directly connected to their interfaces. 
They have no knowledge of remote networks until a routing protocol or static routes 
are configured. 

In this lab we use RIPv2 (Routing Information Protocol version 2). RIPv2 is a distance-vector 
routing protocol that uses hop count as its metric (maximum 15 hops). It supports classless 
routing (VLSM/CIDR), sends updates as multicast (224.0.0.9), and includes the subnet mask 
in updates. 

Once RIPv2 is enabled and the directly connected networks are advertised with the network 
command, every router will dynamically learn all remote networks and end-to-end connectivity 
will be achieved across the entire topology.

--------------------------------------------------
R1 CONFIGURATION
--------------------------------------------------
Command                                      Explanation
-------------------------------------------  -----------------------------------------------
enable                                       Enter privileged EXEC mode.
configure terminal                           Enter global configuration mode.
hostname R1                                  Assign the hostname R1 to the router.
interface g0/1                               Enter interface configuration mode for GigabitEthernet0/1.
ip address 192.168.12.1 255.255.255.0        Assign IP address and subnet mask to the interface.
no shutdown                                  Administratively enable the interface.
exit                                         Exit interface configuration mode.
interface g0/2                               Enter interface configuration mode for GigabitEthernet0/2.
ip address 192.168.13.1 255.255.255.0        Assign IP address and subnet mask to the interface.
no shutdown                                  Administratively enable the interface.
exit                                         Exit interface configuration mode.
interface g0/0                               Enter interface configuration mode for GigabitEthernet0/0.
ip address 10.10.10.1 255.255.255.0          Assign IP address and subnet mask to the interface.
no shutdown                                  Administratively enable the interface.
exit                                         Exit interface configuration mode.
router rip                                   Enter RIP routing process configuration mode.
version 2                                    Set RIP to version 2 (classless, multicast updates).
network 192.168.12.0                         Advertise the 192.168.12.0 network into RIP.
network 192.168.13.0                         Advertise the 192.168.13.0 network into RIP.
network 10.10.10.0                           Advertise the 10.10.10.0 network into RIP.
no auto-summary                              Disable automatic route summarization (keep classless).
exit                                         Exit RIP configuration mode.
end                                          Return to privileged EXEC mode.
copy running-config startup-config           Save the running configuration to NVRAM.

==================================================
EXPECTED RESULT
==================================================
Each router should display three directly connected (C) networks and five RIP (R) routes 
in the routing table (learned via RIPv2). 

After configuring the IP addresses on all PCs, every PC should successfully communicate 
with every other PC across all four LANs through the dynamically exchanged RIPv2 routes.

The command "show ip protocols" should confirm that RIPv2 is running, auto-summary is disabled, 
and the correct networks are being advertised.
